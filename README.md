# 🚗 Ola Data Analysis Project

### 📊 Overview

This project analyzes **Ola ride booking data** using **SQL** and visualizes insights through **Power BI**.
It aims to uncover patterns in bookings, cancellations, customer behavior, and driver performance.

---

### 🧰 Tools & Technologies

* **SQL (MySQL)** – Data cleaning, transformation, and analysis
* **Power BI** – Interactive data visualization
* **Excel / CSV** – Used for data import and preprocessing (if applicable)

---

### 🧮 SQL Analysis

The SQL script (`ola.sql`) includes analytical queries and view creation for:

* Retrieving all successful bookings
* Average ride distance for each vehicle type
* Total number of rides canceled by customers
* Top 5 customers with the highest number of rides
* Rides canceled by drivers due to personal and car-related issues
* Maximum and minimum driver ratings for Prime Sedan rides
* Average customer rating per vehicle type
* Total booking value of successfully completed rides
* Incomplete rides and their reasons

---

### 📈 Power BI Dashboard

The Power BI dashboard (`ola_dashboard.pbix`) visualizes:

* Ride success and cancellation distribution
* Customer and driver rating insights
* Revenue and booking value analysis
* Vehicle-type performance

### ⚙️ How to Run

1. Import the dataset into **MySQL Workbench** or any SQL IDE.
2. Run `ola.sql` to create the required views and queries.
3. Open `ola_dashboard.pbix` in **Power BI Desktop**.
4. Connect it to your local dataset (if needed).

---

### 🏁 Key Insights

* Prime Sedan rides have the highest customer satisfaction.
* A majority of cancellations occur on the customer side.
* UPI is among the most preferred payment methods.
* A small segment of customers contributes to a large portion of total rides.
